CREATE A NEW CAMPAIGN

To create a new campaign, fill in the following fields and then click on the button "Create".

* Action kind
(Open Letter, Letter of Support, Statement, Declaration, Petition). Used as a subtitle in the header and in the button "Sign the ...".

* Action title
Displayed in the page header

Action subtitle
Displayed above the main text in bold (may be left blank)

* Action slug
A unique string that will be used as part of the campaign URL

Action text

Sort signatories alphabetically (by first name)
If False, signatories will be ordered chronologically with the first signature at the top of the list.



Allow anonymous signatories
If True, the number of anonymous signatories will be tabulated at the bottom of the list.



Activate campaign on creation
If False, you will be able to make modifications before opening the campaign for signatures. The campaign will need to be activated later using the Edit button.
